# القناص — Mustafa v5

واجهة عربية لرصد نشاط العملات الرقمية Spot، مع بيانات مشتقات للاستدلال فقط.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root) → Save.

الواجهة تتصل بالمصادر العامة مباشرة، دون مفاتيح أو أوامر تداول. كل زائر يحفظ متابعته ومراكزه في متصفحه فقط. GitHub Pages لا يشغل خادم Node، ولا رصد مضمون عند إغلاق الصفحة. بعض المصادر قد تمنع CORS أو الوصول حسب المنطقة، فيظهر نقص المصدر صراحة. لا ترسل بياناتك إلى proxy عام غير موثوق. التغطية جزئية؛ لا دليل حيتان أو أرباح مضمونة.

لا يتضمن هذا المستودع بيانات تشغيل شخصية أو سجلات سوق مخزنة أو أسراراً.
