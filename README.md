# القناص — Mustafa v5.1

واجهة عربية لرصد نشاط العملات الرقمية Spot، مع بيانات مشتقات للاستدلال فقط.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root) → Save.

الواجهة تتصل بالمصادر العامة مباشرة، دون مفاتيح أو أوامر تداول. كل زائر يحفظ متابعته ومراكزه في متصفحه فقط. GitHub Pages لا يشغل خادم Node، ولا رصد مضمون عند إغلاق الصفحة. بعض المصادر قد تمنع CORS أو الوصول حسب المنطقة، فيظهر نقص المصدر صراحة. لا ترسل بياناتك إلى proxy عام غير موثوق. الكشف الأولي يشمل أزواج Spot/USDT النشطة المتاحة عبر API على Binance وMEXC؛ ليس جميع العملات المدرجة خارج API. ميزانية الشموع100زوج افتراضياً (25/50/100/200 قابلة للتغيير)،40% منها مرور دوري، والأسماء النشطة تُتابع لاحقاً. قراءة الأسعار العامة تسرّع الاكتشاف، والشموع الحديثة شرط الإشارة. CVD في شموع MEXC غير متاح. إشارات جديدة أو تحولات مهمة تُنبه بعد التفعيل، دون تكرار الحالة نفسها. سجل التغطية يوضح سبب عدم فحص أي زوج. التغطية العميقة جزئية؛ لا دليل حيتان أو أرباح مضمونة.

## تفعيل MEXC على الموقع المنشور

MEXC لا يعيد رأس CORS للمتصفح. النسخة المحلية تستخدم الخادم المحلي؛ GitHub Pages يحتاج خدمة market-data المرفقة. يمكن نشر render.yaml على خطة Render المجانية من حسابك، ثم حفظ عنوان الخدمة من إعداد خدمة البيانات في الرادار. لا مفاتيح ولا بيانات حساب؛ المصدر عام، والمسارات مقيدة. لم تُفعّل استضافة الخدمة الخارجية تلقائياً؛ يلزم ربط حساب الاستضافة. قد تنام الخطة المجانية وتحتاج بدءاً بارداً.

لا يتضمن هذا المستودع بيانات تشغيل شخصية أو سجلات سوق مخزنة أو أسراراً.
